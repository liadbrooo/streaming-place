# Streaming Place

Cinematic streaming discovery showcase with responsive layout, search, provider filters, watchlists, title details, and immersive muted trailer previews.

## Deployment

Static website. Vercel automatically deploys the `main` branch. No build command or environment variables needed.

## Note

Streaming Place is a discovery showcase, not a licensed playback service. Streaming availability may change; trailers are embedded from YouTube where available.
